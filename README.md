# Instinct
This game was made for Texas Game Jam. I made it within 48 hours, so it is incomplete but has one playable level. The goal is to collect all of the keys in the level to enter the portal and win. 

**How to play**
Collect all of the keys(For level 1, there are only 3), then touch the keyhole to gain access to a portal. This will allow you to complete the level.
There are enemies, attack them to defeat them.
If you see a crystalized rock, break it by attacking. There may be a key inside. 

**Controls**
WASD to move, the mouse for camera controls, tab to toggle the mouse, spacebar to jump, and o to attack.
